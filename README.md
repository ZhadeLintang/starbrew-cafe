# Brewora Coffee

Brewora is a modern premium coffee shop website built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, React Router DOM, Lucide React, and Zustand.

## Features

- Starbucks-inspired emerald green visual system
- Custom Brewora SVG logo and wordmark
- Responsive Home, Menu, Product Detail, Cart, About, and Contact pages
- Product search and category filters
- Cart persistence with local storage
- Wishlist/favorites system
- Dark mode support
- Toast notifications
- Loading skeletons
- Scroll reveal animations
- Mobile glassmorphism navigation drawer

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
